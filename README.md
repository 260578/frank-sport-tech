# Frank Sport Tech - Landing Page Oficial ⚡

Sitio web oficial de **Frank Sport Tech** ([frank-sport-tech.com](https://frank-sport-tech.com/)).
Entrenador Personal en Madrid y Asesor Nutricional Online en toda España.

## 🛠️ Tecnologías
- **Frontend:** React 19 + Vite 8
- **Estilos:** Dark Titanium Minimal Design System (Vanilla CSS moderno)
- **Iconos:** Lucide React
- **Hosting & Deploy:** Railway
- **Dominio & DNS:** Cloudflare

## 🚀 Despliegue en Railway
1. Conecta este repositorio en Railway.
2. Railway detectará automáticamente el proyecto Node.js / Vite.
3. El comando de build es `npm run build`.
4. El comando de inicio configurado es `npm start` (`vite preview --host 0.0.0.0 --port ${PORT:-4173}`).
5. Configura tu dominio personalizado `frank-sport-tech.com` en los ajustes de Networking de Railway hacia Cloudflare.
